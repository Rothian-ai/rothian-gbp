Security rules made coding agents better, not safe: most rule-equipped sessions in one benchmark still wrote vulnerable code.

In October 2026, Arnica tested six coding agent setups on feature tickets with no security wording. A security rules file cut wrong security decisions from 47% to 17%, above all on authorisation and secrets, but rate limits, race conditions and session handling did not improve and breaking changes doubled. Write the rules, then keep scanners and merge gates as if you had not.
